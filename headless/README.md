# headless/ — exercise 5

Files for the exercise "Claude Without You Watching". The sheet
(`exercises/session5.html`) tells you when to use each one.

| File | What it is |
| --- | --- |
| `gate.py` | The review gate. You fill in two parts in task 2. |
| `team-rules.md` | The team rules the gate checks against. |
| `fix.py` | The fix run. It sends the gate's findings to Claude, who edits the code. You run it in task 3. |
| `claude-review.yml` | Appendix: the gate as a check on every pull request. |

Your own files go in `headless/out/`. Git ignores them.
